# 异世界小满物语 ～社畜少女与梗之力～ 🎮

一个纯前端（零依赖、零构建）的网页冒险 RPG。社畜游戏策划**林小满**在加班的深夜被卡车君送到「梗力」驱动的**艾梗大陆**——魔王散播班味，四天王卷饼互怼，摸鱼女神躺平三百年。而你要做的，是把所有人，都捞下班。

![类型](https://img.shields.io/badge/类型-回合制RPG-blue) ![平台](https://img.shields.io/badge/平台-浏览器-green) ![时长](https://img.shields.io/badge/主线-3小时+-orange)

## 🚀 怎么玩

**方式一（推荐）**：任选一种启动本地服务器，然后浏览器打开 `http://127.0.0.1:8765`

```bash
# 在本项目目录下，任选其一：
python tools/server.py        # 自带 no-cache 头的开发服务器
python -m http.server 8765    # 或用 Python 自带的
npx serve .                   # 或用 Node
```

**方式二**：直接双击 `index.html` 也能玩（所有脚本为经典 script 加载，无 CORS 问题）。

- 鼠标/触屏点击操作，也可以：**Enter/空格** 推进对话 · **1-4** 选选项 · **Esc** 菜单 · **M** 静音
- 进度自动保存在浏览器 localStorage，换设备可用「系统 → 传送码」导出/导入

## 📁 目录结构

```
├── index.html          入口
├── css/style.css       全部样式（复古JRPG × CRT扫描线）
├── js/
│   ├── engine.js       核心：状态/存档/WebAudio合成器/数值
│   ├── data.js         数据：职业/技能/物品/敌人/商店/成就/扭蛋
│   ├── memes.js        梗图鉴 133 条
│   ├── ui.js           UI：打字机对话框/剧情执行器/菜单/商店
│   ├── battle.js       回合制战斗（状态/合体技/Boss机制）
│   ├── world.js        行程图/委托板+讨伐悬赏/5个小游戏
│   ├── map.js          瓦片地图引擎（Canvas渲染/网格移动/遭遇/互动）
│   ├── maps_data.js    19 张地图数据
│   ├── main.js         标题画面/存档槽/计时
│   └── story/          剧情：ch0~ch8 + side(支线) + post(后日谈)
└── tools/
    ├── validate.js      剧情数据静态校验器（场景/物品/成就引用完整性）
    ├── validate_maps.js 地图数据校验（行宽/实体落点/出口互连）
    ├── bracket_scan.js 括号平衡扫描器
    └── server.py       开发服务器（no-cache）
```

## 🛠️ 开发自检

```bash
node tools/validate.js       # 校验 147 个场景的全部引用（应输出 ✅ 无错误）
node tools/validate_maps.js  # 校验 19 张地图的数据（应输出 ✅）
```

## ⚠️ 兼容性说明

- 推荐 Chrome / Edge 现代浏览器；所有表情符号已选用 Windows 10 可渲染的版本
- 存档依赖 localStorage：隐私模式下关闭页面会丢档，长期游玩建议定期导出传送码
- 音频需要页面有一次点击交互后才会启动（浏览器策略）
